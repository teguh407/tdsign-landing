02 — THE AI LAYER

Built with Claude.

Claude runs inside the production products — not as a demo, but as part of daily operations. Every AI feature ships behind the same standard: deterministic fallback, graceful degradation, user-visible sources.

Semantic search over the catalog

Bluvia's 4,592-title catalog is indexed for meaning, not keywords. A query like “drama Korea tentang balas dendam keluarga” resolves to the right titles — including ones the metadata never spells out.

CLAUDE HAIKU · RERANKING · <300MS P95

Synopses that stay on-model

Episode summaries are drafted from source metadata and validated against the title's canonical facts before they reach the app. A deterministic checker rejects anything that invents a character, arc, or episode.

CLAUDE SONNET · GROUNDED GENERATION · FACT-CHECK GATE

Operator-side reporting

Internal dashboards turn raw pipeline events into plain-language summaries — what synced, what failed, what drifted — so operations run from a phone instead of a SQL console.

CLAUDE SONNET · STRUCTURED OUTPUT · INTERNAL TOOLING

How we integrate. Claude is called through the Messages API with structured outputs and strict schemas. If the model is unavailable, times out, or returns something the schema rejects, the product serves the exact same experience without it. No user-facing surface depends on a model being up.
